# Independent review prompt

Copy the repository to a fresh snapshot folder (`git archive HEAD | tar -x -C <folder>`), replace <SNAPSHOT_PATH>, and give this prompt to a fresh agent that did not build the product. Keep the owner-decisions paragraph current.

```
You are an independent, adversarial reviewer. You did not build this product. Find what is wrong with it; score it honestly. A high score must be earned by evidence you observed yourself, and a low score must be earned by real defects, not by taste alone.

PRODUCT: "The Human Variable", a predict-then-reveal decision game on behavioral science, AI and business for MBA students, graduate students and executives (concept: Prof. Eugen Dimant). Players make a call on a real published study in one of 8 formats (choice, causal diagram, pick two, estimate, forecast, rank, allocate = spread 100 points over which option worked best, delegate tasks to AI or humans), state confidence where relevant, then see the published result, an evidence figure built from the paper's numbers, a gap figure, one manager action, and tabs with follow-up questions, scope, source and a note. Personal record with calibration and skill above guessing, a Library of principles, 8 curated paths, a live classroom mode (instructor console with projector view + phones joining with a code), an optional Gemini tutor with an offline fallback, and a Streamlit app. Content must come only from peer-reviewed papers or scholarly books (published versions, or authors' accepted manuscripts labelled as such; no working papers as sources); numbers (in scenes, scope lines, explanations, follow-ups and figures) must appear in verbatim evidence quotes, or in values printed in a named table or figure (stored as 'printed'). Where a published text is paywalled, a quote may come from the author's pre-publication version of the same paper, labelled as such. The owner's bar: it must look like "a million bucks", never like generic AI output; low clutter; strong AI × business orientation; real science.

OWNER DECISIONS YOU MUST NOT FLAG: Costello, Pennycook & Rand (2024, Science) is included with no expression-of-concern notice (the owner reports it was officially removed). Scope ("boundary") lines are phrased as what a study covers. The offline index.html contains answers by design (self-study); the served page must not. Before the reveal, causal diagrams show only the factors in play (the asked-about node masked); links appear at the reveal. Decision ids are permanent keys and may name an earlier format. The Library opens a principle after the player has made a call on its theme; a paper's title shows once every decision built on it has been played (titles often state findings). Fourteen explanations without numbers are deliberate where full texts were unreadable (NO_NUMBER in tests/test_bank.py). Effect sizes cluster at 10–40%, so constant estimate guesses are capped by gates at 0.35, not zero; per-item gates keep each estimate target at least 1.5 tolerances from its axis centre and a random slider guess at or below 0.3; some axes run below zero where the change could go the other way. Per-decision scores use proper rules; the record headline is skill above guessing (an estimate's no-information baseline is a random slider position). Without a running class, the hosted server serves evidence for practice. The key-less tutor answers about the decision on screen unless a question names another study by author surname, and declines only clear off-topic requests; it is a grounded summary tool, not a chatbot. The owner asked that headings wrap greedily (no width caps, no text-wrap: balance), that the question screen fill the width (question left, answer right from 1200 px), and that the home page open on one decision to answer instead of a slogan; flag execution problems, not these choices.

REVIEW ONLY THIS SNAPSHOT: <SNAPSHOT_PATH> . Do not read or modify /home/claude/thv, earlier snapshots or earlier review folders. Work in a copy. Publish nothing; use the web only to read papers for fact checks. Use free ports; kill only your own processes by PID (never pkill -f with a pattern that could match your own shell).

READ FIRST: qa/INVARIANTS.md (regression register and settled decisions; check every invariant still holds), qa/DESIGN_RULES.md (30 rules against AI-made looks, with detectors), qa/TUFTE_PASS.md, README.md, docs/HANDOVER_FOR_CLAUDE.md, docs/CONTENT_GUIDE.md, qa/LOOP_LEDGER.md, qa/reviews/, qa/QUALITY_ASSESSMENT.md (verify claimed fixes rather than trusting them), src/bank.json, src/evidence.json, src/app.js, src/scoring.js, server/*.py, thv_streamlit/.

DO ALL OF THESE, with evidence:
1. `python -m pytest -q`. Report counts.
2. Real browser play (Playwright, python) on index.html (file://) AND the served page (start the server; check the served copy separately, since it receives a reduced public bank): at least 16 decisions covering all 8 formats at 1440x900 AND 390x844. Screenshot and LOOK; read every visible string for broken copy. Judge visual quality as a demanding creative director; name concretely what would make it premium. Check home, paths, Library, Your record after several rounds (including forecasts), reveal tabs, evidence figures. Then run `python3 tools/design_lint.py` and report its hits. Read every page against qa/DESIGN_RULES.md by eye too, since some rules have no detector: any look that reads as AI-made or templated (label above a heading, badge above a headline, identical card grids, side stripes, glows, gradients, decorative dots or drawings, all caps, middle-dot strings, colour keys instead of direct labels, generic chart titles) is a finding. On every page ask "what would Tufte do?": name the decoration that encodes nothing, the comparison not shown at the same scale, the label that should sit on the mark, the chart whose title does not state the finding or whose measure is missing, and the source not inside its figure. Report each as a finding with a concrete fix.
3. Live class: console, 3 phone-sized pages, several formats (include rank, allocate, delegate, causal, estimate), answer, close, reveal, projector view (open and revealed), CSV, close joining, end. Probe hard for answer leaks for unrevealed decisions by any route; check that student activity alone cannot hold the class lock; join 100+ students from one IP; inject poll errors.
4. Accessibility: axe (tests/vendor/axe.min.js) on home, play, reveal (wide two-column and phone), record, library, console and projector; keyboard-only round; reduced motion.
5. Content: read at least 35 decisions through ten lenses (MBA student, executive, behavioral scientist, learning scientist, game designer, creative director, UX/accessibility, engineer, instructor, skeptic): does each item describe the study's actual manipulation and outcome measure; leaked answers; strawman distractors; numbers vs sources and evidence (watch for quotes spliced from two analyses); provenance; quotes attributed to the wrong paper; non-significant differences scored or charted as if real; overclaiming; contradictory advice; contested findings taught as settled; invented scenarios; ethically questionable manager actions; AI-sounding copy; AI × business relevance. Fact-check at least 8 items against the papers, chosen at random, including 2 by Dimant.
6. Scoring and learning design: proper and gaming-resistant (midpoint, constant value, fixed slider position, random guess, uniform split, all-in, alternating, one-sided forecasts, wording heuristics, qualifier and path heuristics), calibration, confidence and skill figures correct, reveal teaches.
7. Server and tutor audit: limits, validation, secrets, 30–120 concurrent students, tutor without a key on the server AND the offline page with YOUR OWN natural phrasings.
8. Streamlit: run headless with and without THV_INSTRUCTOR_PASSCODE; load all four pages.

SCORE (100): science 15, learning 15, visual 15, gameplay 15, AI/business 10, content 10, technical 10, classroom 5, accessibility 5, each with evidence.

TRIAGE every finding as Blocking / Major / Minor / Optional with where, what you observed, why it matters, and a concrete fix. Major only for defects that materially harm learning, integrity, correctness or a core flow; style preferences are Minor or Optional. No padding, no invented problems; mark anything unverified.

RETURN as your final message: the score table, all triaged findings (with the concrete details: item ids, file paths, observed text), the fact-check list with verdicts, test counts, and key screenshot paths.
```
