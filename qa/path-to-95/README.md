# The Human Variable: path to 95

This is the package for taking the game from about 81 to 95+ on a fixed rubric with blind reviewers. Written 2026-11-17 against iteration 90 (commit 86d5529).

| File | What it is |
|---|---|
| HANDOVER_PROMPT.md | The prompt to paste into a session that can run a browser. Start here. |
| RUBRIC_v1.md | The frozen scoring sheet: 7 hard gates, 20 pass/fail criteria, the pass bar |
| OWNER_DECISIONS.md | Defaults for the five caps that only Eugen can settle |
| REVIEW_PROTOCOL.md | The board, the holdout, calibration, the blind review and the owner board |

Nothing here changes the game. Nothing merges to master or goes to gh-pages without Eugen's OK.
